# 4位加法器 (Adder4) 设计说明

## 1. 设计思路与位宽扩展
这是一个四位加法器。虽然输入 `a` 和 `b` 是 4 位，加上进位输入 `cin`，其最大值达到 `15 + 15 + 1 = 31`（即需要 5 位来存储结果）。

*   **位宽处理**：由于输出信号 `sum` 定义为 4 位，无法直接表示最高位的进位。
*   **拼接语法**：需要利用拼接语法 `{cout, sum}` 将进位输出 `cout` 与和 `sum` 拼接起来，组合形成一个 5 位的向量，以正确表示完整的计算结果。

## 2. Testbench 测试策略
在测试代码中，采用了以下策略进行验证：

*   **消除竞争冒险**：使用 `#10` 延时，目的是防止激励信号的变化与结果检查发生冲突，避免抓到电路状态改变前的“旧值”。
*   **穷举法验证**：由于输入位宽有限，采用穷举法遍历了所有可能的输入组合，共获得 512 个测试向量，对编写的 `adder4` 模块进行了全面的测试验证。
